# Ostler default theme

Colours, wallpapers and gauge styles.

Part of [Ostler](https://github.com/openostler/ostler), an open, local-first,
smart-home-like ecosystem for your car. Ostler is built like a phone OS: the
platform repo is the bare system, and every feature is an app or pack in its
own repo, installed from the Store.

Status: empty. This project follows UX first: design, then UI against
recorded fixtures, then wiring. Nothing is built here until the app's design
brief is approved. The briefs live in
`openostler/ostler/references/design/2026-10/brief/`.

Licence: AGPL-3.0-or-later. Contributions are
accepted under the project CLA.

Code is AGPL-3.0-or-later; artwork (wallpapers, images) is CC BY-SA 4.0.

## What this repo holds

- **Owner in the brief:** `theme pack`.
- **Contents:** Ostler Night, Day, Night dim and Deep night as a theme pack (the token names and safety colours stay in the OS).
- **Design brief:** [45-launcher-j](https://github.com/openostler/ostler/blob/main/references/design/2026-10/brief/45-launcher-j.md), [45-launcher-k](https://github.com/openostler/ostler/blob/main/references/design/2026-10/brief/45-launcher-k.md) (index: [99-index](https://github.com/openostler/ostler/blob/main/references/design/2026-10/brief/99-index-a.md)).
- **Spec:** [visual-design-system](https://github.com/openostler/ostler/blob/main/specs/2026-10-07-visual-design-system-design.md), [launcher-and-widgets](https://github.com/openostler/ostler/blob/main/specs/2026-10-07-launcher-and-widgets-design.md).
- **Code that moves here later** ([ADR-0046](https://github.com/openostler/ostler/blob/main/decisions/adr-0046-empty-os-every-app-an-add-on.md)): the values in `ui/tokens/`. It moves only after this app's designs are approved ([ADR-0045](https://github.com/openostler/ostler/blob/main/decisions/adr-0045-ux-first.md)).
